# ✨ Handcrafted Cinematic Portfolio // Special Grade Creative Dev

> **Anime × Cinematic × Creative Portfolio × Premium UI/UX × Playful Motion**
> Built with React 19, Tailwind CSS v4, Framer Motion, and synthesized Web Audio.

---

## 🌟 Key Highlights

- 🎬 **Interactive Cinematic Intro:** Progressive aperture reveal with diagnostic HUD readouts, speedlines, audio fanfare, and smooth skip capability.
- ⚡ **Recruiter 15-Second Executive Scan:** Instant scannable overview designed specifically for hiring managers and recruiters. Accessible globally from the header or by pressing **`[R]`** on the keyboard!
- 🎴 **Collectible Trophy Vault:** Certificates visualized as collectible holographic trading cards with rarity tiers (`LEGENDARY`, `MASTER`, `VERIFIED`), iridescent foil shimmer, and high-fidelity verification modals.
- 🚀 **Interactive Project Showcase:** The star of the portfolio—styled as high-tech manga cartridges with handcrafted SVG architectural diagrams, live metrics, tech stack pills, and deep-dive architectural dossiers.
- 👾 **Aura Companion Mascot:** Interactive floating anime spirit that reacts to mouse clicks, blinks, changes dialogue bubbles, triggers celebratory confetti bursts, and plays synthesized audio chirps.
- 🎨 **4 Anime Aura Palettes:**
  - **Sakura Drift** (Warm Coral & Sunset Pink)
  - **Neo Shibuya** (Electric Cyan & Neon Azure)
  - **Viper Jade** (Vivid Anime Emerald & Mint)
  - **Amethyst Void** (Deep Cyber Purple & Neon Magenta)
- 🔊 **Zero-Asset Synthesizer Audio Engine:** Pure Web Audio API synthesizing retro-futuristic blips, chirps, wooshes, and fanfare without needing any external audio assets. Fully toggleable with a 1-click mute button.
- 📜 **100% Placeholder Modular Configuration:** All personal information, projects, skills, certificates, and social profiles live in a single, well-documented configuration file: `src/data/portfolioData.js`. Zero fake biographies or assumed achievements.

---

## 🛠️ How to Customize Your Portfolio

Open **`src/data/portfolioData.js`** and update the placeholders:

```javascript
export const personalInfo = {
  name: "Your Real Name",
  handle: "@yourhandle",
  title: "Your Professional Title",
  tagline: "Your punchy personal tagline",
  location: "Your City / Remote",
  email: "your.email@domain.com",
  github: "https://github.com/yourusername",
  linkedin: "https://linkedin.com/in/yourusername",
  // ...
};
```

Everything across the hero, projects showcase, skills matrix, trophies, recruiter scan, and contact form updates automatically!
